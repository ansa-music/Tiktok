## Цель и правила
- Цель: 1000 подписчиков суммарно на YouTube и TikTok. Аудитория англоязычная (США и Великобритания).
- Формат: вертикальные Shorts 1080×1920, без голоса и липсинга, только музыка, звуковые эффекты и моушн-графика. Все тексты в роликах и подписях на английском.
- Запрещено: боты, накрутки, покупка подписчиков, спам. Отметки «для детей» и «AI-generated» ставь честно.
- Перед публикацией пересчитывай каждый факт и просматривай ключевые кадры: текст не обрезан, опечаток нет.

## Как сделать ролик
```bash
git clone https://github.com/ansa-music/Tiktok && cd Tiktok && git checkout ajent21-media
pip install numpy scipy        # нужны ещё ffmpeg, Playwright с Chromium, шрифты Inter Display и JetBrains Mono
cd pipeline
node scripts/render.js scripts/<scene>.html frames/<scene> 30 "1.5,5,10"   # проверочные кадры
node scripts/render.js scripts/<scene>.html frames/<scene> 30             # все кадры
python3 scripts/sfx.py scripts/<scene>_cue.json out/<scene>.wav
ffmpeg -y -framerate 30 -i frames/<scene>/f_%05d.jpg -i out/<scene>.wav -c:v libx264 -crf 20 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest -movflags +faststart out/<file>.mp4
```
Новую сцену делай по образцу: `cosmic.html` или `ocean.html` для рубрики SCALE (инфографика), `ep2.html` для аниме-серий. Подключай `lib.js` и `lib2.js`.

**Правила монтажа:**
- действие с первого кадра;
- смена картинки каждые 2–3 с;
- ключевой текст держится на экране не меньше 1 с;
- плашка `ctaPill()` («FOLLOW…») на 40–45% длины ролика;
- в конце без затемнения в чёрный, чтобы ролик зацикливался;
- длина 13 с или до 30 с.

## Как опубликовать (работает без участия владельца)
Из этой облачной среды загрузить файл на внешние сервисы нельзя: сеть обрывает загрузку. Публичную ссылку даёт только GitHub:
1. Положи mp4 в корень ветки `ajent21-media`, затем `git commit` и `git push origin ajent21-media`.
2. Ссылка на файл: `https://raw.githubusercontent.com/ansa-music/tiktok/ajent21-media/<file>.mp4`
3. Вызови Metricool `createScheduledPost` с этой ссылкой в `media`. Metricool сразу копирует файл к себе.

**Настройки поста:**
- providers `youtube` и `tiktok`;
- `youtubeData`: type `short`, privacy `public`, `madeForKids: false`, `isAiGeneratedContent: false` (для роликов из кода);
- категория `EDUCATION` для SCALE, `FILM_ANIMATION` для аниме;
- `tiktokData`: `PUBLIC_TO_EVERYONE`, `isAigc: false`.

**Текст поста:**
- название до 40 символов, ключевое слово первым;
- 3–5 хэштегов;
- в описании вопрос к зрителю.

**Время:** 21:00 и 23:30 по Казахстану. Это 12:00 и 14:30 в Нью-Йорке.
