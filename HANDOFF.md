## 6. Стратегия (из claude-youtube + наши данные)

- **Две рубрики (Hub):** `SCALE #N` (научные масштабы, лучший формат) и сериал `AJENT21 Ep.N` (аниме-самурай, интерактивный сюжет).
- **Частота:** 1–3 Shorts в день. Окно свежести Shorts ~28–30 дней, пауза обрушивает охват.
- **Время публикации:** 21:00 и 23:30 по Казахстану (12:00 и 14:30 в Нью-Йорке).
- **Хук:** первые 1–3 с решают всё, без медленных стартов и логотипов. Проверять метрику «Viewed vs Swiped Away» в YouTube Studio: если ниже 60%, переделывать начало.
- **Удержание:** смена картинки каждые 2–3 с, полоска прогресса, ключевой факт держится не меньше 1 с.
- **Длина:** 13 с или до 30 с; 30–45 с — «мёртвая зона».
- **Петля:** конец перетекает в начало, без затемнения в чёрный.
- **CTA посреди ролика** (только ~16% досматривают до конца): плашка «FOLLOW…» на 40–45% хронометража.
- **Метаданные:** название до 40 символов, ключевое слово первым; 3–5 хэштегов; вопрос к зрителю в описании.
- **Музыка:** только своя или сгенерированная. Лицензионный трек забирает 50% дохода Shorts.

## 7. Конвейер видео (бесплатный, без лимитов)

Всё в `02-pipeline/`. Рисуется на `<canvas>` в Chromium (Playwright), звук синтезируется на Python и смешивается с реальными SFX Mixkit, сборка в ffmpeg.

```
02-pipeline/
  scripts/render.js        # кадры: node render.js <scene.html> <outDir> [fps] [t1,t2 для проверочных кадров]
  scripts/lib.js           # общая графика: небо, солнце, горы, герой, лепестки, вспышки, камера, CTA-плашка
  scripts/lib2.js          # луна, крыши-пагоды, фонари, ниндзя
  scripts/ep1..ep3.html    # аниме-серии
  scripts/cosmic.html      # SCALE #1 «Вселенная за один год»
  scripts/ocean.html       # SCALE #2 «Глубина океана»
  scripts/*_cue.json       # партитура: секции музыки + удары SFX по таймингу
  scripts/sfx.py           # синтез музыки и SFX + наложение реальных сэмплов
  assets/sfx/*.mp3         # 14 SFX Mixkit (лицензия в assets/sfx/LICENSES.md)
```

**Сборка одного ролика:**
```bash
cd 02-pipeline
pip install numpy scipy            # один раз
node scripts/render.js scripts/ocean.html frames/ocean 30
python3 scripts/sfx.py scripts/ocean_cue.json out/ocean.wav
ffmpeg -y -framerate 30 -i frames/ocean/f_%05d.jpg -i out/ocean.wav \
  -c:v libx264 -crf 20 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest -movflags +faststart out/ocean.mp4
```
Нужно: Node 18+, `npm i playwright` (с Chromium), Python 3 с numpy/scipy, ffmpeg, шрифты Inter Display и JetBrains Mono, Noto Color Emoji.

**Проверка перед публикацией:** отрендерить ключевые кадры (`render.js ... 30 "1.5,4,8"`), склеить в контрольный лист `ffmpeg ... hstack` и просмотреть: текст не обрезан, нет опечаток, факты верные.

## 9. Известные ограничения

1. **Автопубликация локальных роликов заблокирована.** Сеть облачного окружения обрывает загрузку файлов наружу (catbox/litterbox отдают 500, хотя домены разрешены). Metricool принимает только публичную ссылку на медиа. Поэтому ролики из конвейера загружаются вручную в Metricool.
   - Вариант решения: запускать конвейер на своём компьютере (там загрузка работает) или через `publish/upload_post.py` из video-shotcraft (сервис Upload-Post, нужен его API-ключ).
2. **Генерация AI-картинок** упирается в кредиты (Higgsfield, Canva, Figma). Бесплатный конвейер (раздел 7) не зависит от них.
3. **TikTok-голоса** не видны через инструменты. Голосование Ep.3 считать по YouTube-комментариям (vidIQ `vidiq_video_comments`) плюс сообщения владельца.
